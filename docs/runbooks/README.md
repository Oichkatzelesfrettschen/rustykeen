# Runbooks

This directory is reserved for operational, task-oriented guides.

Runbooks should provide concrete procedures for supported workflows such as:

- Android builds
- profiling and optimization passes
- release and packaging routines
- platform-specific setup

During the taxonomy transition, many runbooks still live in `docs/` root.

Current runbook entrypoints include:

- `docs/runbooks/android_build.md`
- `docs/runbooks/android_deployment.md`
