# Canonical Docs

This directory is reserved for current source-of-truth documents.

Canonical docs answer questions like:

- how do contributors build, test, and audit locally?
- what architectures and APIs are currently supported?
- what policies govern artifacts, versioning, and target support?

During the taxonomy transition, many canonical docs still live in `docs/` root.
Use `docs/TAXONOMY.md` to guide future moves.

Current canonical entrypoints include:

- `docs/canonical/dev_workflow.md`
- `docs/canonical/api_stability.md`
- `docs/canonical/bitvec_decision.md`
