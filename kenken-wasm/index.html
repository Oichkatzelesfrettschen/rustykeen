🧩 KenKen WASM Solver

Demonstrates modern WASM serialization using opaque handles and serde_wasm_bindgen (2025-2026 best practices)

Puzzle Operations

Architecture: This demo uses the opaque handle pattern - the WASM library stores puzzles in Rust memory and returns numeric handles. This avoids expensive serialization/deserialization and is the 2025-2026 best practice for WASM-JavaScript interop.

API Flow:
  1. create_test_puzzle() → returns handle (u32)
  2. solve_puzzle_handle(handle) → returns solution JSON
  3. free_puzzle(handle) → cleanup (optional in this demo)
